# TRANSFORMER ALGORITHM IN JAVA FROM 0

### The goal of this repository, is to make a transformer algorithm from 0, using 0 frameworks or prebuilt libraries, to understand how a transformer actually work.

I tried my best to comment the code, and i've also made a video on how the repository work on youtube.

## Goal of the algorithm: 

Do a next token prediction on a unfinished word. predict what can be the continuation of the word. example: 

Input: "Hel"

Output: 

"Hello", "Hell", "Help" ...
